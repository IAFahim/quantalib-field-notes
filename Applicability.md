# Applicability vs needle-cs — verdict on every trick

Attribution: QuanTAlib patterns observed in mihakralj/QuanTAlib (Apache-2.0);
anchors at `c6ffb9f4`. needle-cs anchors at `ec5a00d` (`src/Needle/…`).
Compatibility lens: fully-unmanaged/Roslyn direction — reflection-free,
AOT-safe, blittable preferred; `double`-only tricks must be re-expressed for
fp32/int8-quant; net48-only shims are irrelevant (needle-cs is modern
net-only + native).

Verdicts: **USE** = port as-is (target file:line + expected gain + effort) ·
**ADAPT** = port with stated changes · **SKIP** = do not port (reason).
Effort: **S** <1 day · **M** 1–3 days · **L** >3 days (flagged, rare).
Every catalog ID from `Tricks.md` appears exactly once below — no maybes.
