## 1. SIMD kernel patterns (`lib/`)

Global dispatch: tier order is always `Avx512F → Avx2/FMA → AdvSimd → scalar`,
gated by `#if NET5_0_OR_GREATER` (e.g. `lib/statistics/variance/Variance.cs:198-220`,
`lib/core/simd/SimdExtensions.cs:717-732`). Two gate styles: windowed stats require
`len >= 256 && !ContainsNonFinite()` (`Sma.cs:290-291`, `Variance.cs:199-200`); cheap
1-lag stencils use tiny width gates (`Slope.cs:192`, `Accel.cs:230`, `Jerk.cs:255`).
Portable fallback is `System.Numerics.Vector<T>` + `VectorCompat.Load`
(`SimdExtensions.cs:139-177`). All SIMD is `double`-only; no float/Half, no Shuffle
LUTs (only WMA static `Vector512<long>` permute indices + masks, `Wma.cs:45-50`).
No exp/log/sqrt approximations — exact `Avx.Sqrt`, scalar `Math.Exp` per lane, clamps
(`StdDev.cs:180`, `Sigmoid.cs:235-239`).
